Slack Integration

Distribute advisory PDFs to Slack. When creating an advisory you pick the target channels, and the PDF is uploaded with a crafted message.

Enable Slack advisory distribution
Test checks the token typed above, but you still have to click Save Settings to keep it.

Required scopes: chat:write, files:write, channels:read, groups:read.

A bot token (xoxb-) only sees channels it has been invited to — run /invite @your-bot in each target channel. A user token (xoxp-) also works and sees your own channels with no invite needed, but posts as you and breaks if your account is deactivated. With a user token the scopes must be granted under User Token Scopes, not Bot Token Scopes.
