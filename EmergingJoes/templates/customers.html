Written in Slack formatting. Text is sent as-is, so mentions like @SOCIberia_DXC and tags like [Security Advisory] survive. Placeholders in <UPPERCASE> are filled in per advisory.

Used for advisories with no CVE. Leave either box empty to fall back to the standard field block.

Available placeholders

Filled from our own data

  • <CVE-ID> — CVE from triage
  • <SEVERITY> — Critical / High / Medium / Low
  • <ADVISORY-DATE> — date the advisory was created
  • <REMEDIATION-DATE> — deadline derived from severity
  • <PDF-FILENAME> — attached file name
  • <CUSTOMER-NAME> — this customer
  • <RECOMMENDATIONS> — action bullets
  • <PRIORITY-BULLET> — priority and due date bullet

Read out of the advisory

  • <VULNERABILITY-NAME> / <THREAT-NAME>
  • <VENDOR-PRODUCT>
  • <CVES> — every CVE covered
  • <ADVISORY-ID>
  • <AFFECTED-VERSIONS>
  • <FIXED-VERSION>
  • <DESCRIPTION>

Any other <UPPERCASE> placeholder you invent is written per advisory from the advisory document. Name it descriptively, as in <WHAT SHOULD BE CHECKED / EXPOSURE CONDITION>, because the name is the only instruction given. Anything unanswerable becomes N/A.
